تطبيق مكتبي يحمي بطارية حاسوبك ويرفع عمرها الافتراضي عبر مراقبة ذكية وتحكم فعلي في حدود الشحن وإشعارات قابلة للتخصيص.

---

## لماذا هذا التطبيق؟

البطارية تتدهور أسرع عندما تبقى مشحونة 100% أو تُفرَّغ تحت 20% باستمرار. القاعدة الذهبية: حافظ على الشحن بين **40% و80%**. BatteryGuardAI يجعل ذلك تلقائياً قدر الإمكان:

1. **مراقبة لحظية** لحالة البطارية والاستهلاك.
2. **تنبيهات ذكية** عند اقتراب الحدود مع تذكيرات متكررة.
3. **تحكم فعلي** في حد الشحن الأقصى على الأجهزة المدعومة (يتوقف الشحن فعلياً عند 80% مثلاً).
4. **تعلم عاداتك** ليعطيك توصيات شخصية وتنبؤاً دقيقاً بالوقت المتبقي.

## التثبيت

```bash
git clone https://github.com/ALSRKAL/BatteryGuardAi.git
cd BatteryGuardAi
pip install -r requirements.txt
python main.py
```

خيارات التشغيل:
- `python main.py` — نافذة كاملة.
- `python main.py --background` — يعمل بالخلفية من أيقونة الصينية فقط.

## شرح التبويبات

### 📊 الحالة
ويدجت بطارية متحرك، النسبة، حالة الشاحن، الوقت المتوقع للفراغ/الامتلاء، استهلاك الطاقة الفعلي (لينكس)، وصحة البطارية من العتاد.

### ⚙️ الإعدادات
- **حدود التنبيه**: حرج/منخفض/أمثل/مرتفع/ممتلئ — كل حد بصنبه.
- **التحكم في الشحن**: حد أدنى وأقصى بمنزلقات + تفعيل التحكم التلقائي (يطلب صلاحيات sudo على لينكس).
- **التشغيل التلقائي** مع النظام، التصغير للصينية عند الإغلاق.
- **التحسين التلقائي**: وضع مستمر/مجدول/عند الطلب مع عتبات CPU/ذاكرة/قرص/طاقة.

### 🤖 الذكاء الاصطناعي
توصيات مخصصة تتحسن مع الاستخدام: ساعات استخدامك المكثف، مستوى شحنك المعتاد، أنماط الشحن الليلي، تنبؤ الساعة القادمة، وكشف الاستهلاك غير الطبيعي. تعرض أيضاً درجة الثقة ومستوى نضج التعلم.

### 📈 الإحصائيات
إجمالي أوقات الشحن/التفريغ، دورات الشحن اليومية، متوسط وذروة الاستهلاك، وسجل أحداث قابل للتصدير والمسح.

## التحكم في حدود الشحن — ماذا يدعم جهازي؟

| المنصة | الطريقة | الحالة |
|---|---|---|
| لينكس | `charge_control_end_threshold` (ASUS/newer kernels) | ✅ الأفضل |
| لينكس | `charge_start/stop_threshold` (ThinkPad) | ✅ |
| لينكس | TLP (`tlp setcharge`) | ✅ إن كان مثبتاً |
| ويندوز | Lenovo Conservation Mode | ✅ حد ثابت ~55–60% |
| ويندوز | Dell Command \| Configure (`cctk`) | ✅ إن توفر |
| ويندوز | HP / ASUS / MSI | حسب الأداة المتوفرة |

إن لم يتوفر أي مسار تحكم، سيرسل التطبيق إشعاراً فقط عند الوصول للحد — ولن يدّعي نجاحاً زائفاً.

## الإشعارات الذكية

- **حدود قابلة للتخصيص** لكل نوع تنبيه.
- **تذكيرات متكررة** لكل تنبيه حرج مع خيارات:
  - ⏹️ **إيقاف** — يوقف التذكير نهائياً.
  - 😴 **غفوة** — يؤجله 10 دقائق (قابلة للتغيير).
  - 🔇 **كتم** — يكتم الصوت.
- **ساعات هدوء** (1–6 فجراً) تخفض الإشعارات غير الحرجة.
- **5 أصوات MP3 مخصصة** حسب نوع الإشعار (حرج/تحذير/معلومة/نجاح/تحسين).

## أسئلة شائعة

**التطبيق لا يرى البطارية؟**
تأكد من وجود `/sys/class/power_supply/BAT0` (لينكس) أو أن WMI يعمل (ويندوز).

**طلب sudo كل مرة؟**
التحكم في الشحن يحتاج كتابة في sysfs. أدخل كلمة المرور عند الطلب مرة واحدة لكل جلسة؛ لا تُخزَّن أبداً خارج الذاكرة.

**أين تُحفظ بياناتي؟**
- لينكس: `~/.config/batteryguard/`
- ويندوز: `%APPDATA%\BatteryGuardPro\`

كل عمليات الحفظ ذرية (لا يتلف الملف عند انقطاع مفاجئ).

**هل يستهلك موارد كثيرة؟**
لا — المراقبة تكيفية (2 ثوانٍ نشطة / 10 ثوانٍ أثناء شحن مستقر)، والتحليل العميق كل 30 عينة فقط، والأيقونة مخزنة مؤقتاً.
